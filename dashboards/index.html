Quick Start

1 · Setup & Deploy

git clone <repo> soc-lab && cd soc-lab chmod +x setup.sh health-check.sh simulate-attack.sh sudo ./setup.sh

2 · Run APT-29 Simulation

./simulate-attack.sh apt29 # Injects 13 MITRE ATT&CK events # into OpenSearch soc-logs-* index ./simulate-attack.sh verify # Confirms events were indexed

3 · Optional — Red Team Profile

docker compose --profile redteam up -d # Starts Responder on lab VLAN # LLMNR/NBT-NS poisoning active # Lab network only!

4 · Optional — Platform Hardening Profile

docker compose --profile platform-hardening up -d # Starts Keycloak, Vault, TheHive+Cortex, # Loki+Promtail, n8n # Then: vault operator init (save unseal keys!)

5 · Optional — Blue Team Extensions Profile

docker compose --profile blue-team-extensions up -d # Starts CyberChef, Arkime, NetBox, # Falco, CrowdSec, Pi-hole # Then: docker exec soc-arkime db.pl \ # http://opensearch-node1:9200 init # Sysmon/osquery: deploy per-endpoint, see # endpoint-configs/windows/{sysmon,osquery}/ # Docker config audit: ./security-scan.sh --docker-bench # Web scan: ./security-scan.sh --nuclei # Slack alerts: set SLACK_WEBHOOK_URL in .env

6 · Endpoint + Infra Hardening (no new containers)

# Wazuh SCA — already in shared-agent.conf # WDAC (audit mode, one host at a time): cd endpoint-configs/windows/wdac .\Deploy-WDAC.ps1 # Ansible — orchestrates all 4 endpoint scripts: cd ansible ansible-playbook -i inventory.local.ini \ playbooks/deploy-endpoint-agents.yml \ -e vector_host=<vector-ip> # Harbor registry (own installer, see config/harbor/README.md)
